# Tiny Rituals Inspired Shopify Theme

This is an original Shopify OS 2.0 theme inspired by the shopping flow, editorial calm, and crystal-jewelry merchandising style of `tinyrituals.co`.

It does not copy the reference site's source code or image assets. The homepage hero image is an original generated asset saved at `assets/hero-crystals.png`.

## Structure

- `layout/theme.liquid` - base Shopify layout
- `templates/index.json` - homepage section order
- `sections/` - editable Shopify sections
- `snippets/product-card.liquid` - reusable product card
- `assets/theme.css` and `assets/theme.js` - theme styling and small menu behavior
- `preview.html` - static local preview of the homepage styling

## Shopify Usage

Upload this folder as a Shopify theme, or connect it with Shopify CLI from this directory. In the theme editor, replace placeholder collection links, product collection settings, and images with store content.
